# Theresa Nwatu Portfolio

A recruiter-ready static portfolio for Theresa Nwatu, focused on Business Intelligence, Data & Business Analytics, Business Analysis, strategy and operational reporting.

## What is included

- `index.html` - complete portfolio site
- `assets/styles.css` - responsive visual system
- `assets/script.js` - project case-study interactions
- `data/` - reserved for safe synthetic/sample datasets
- `Theresa_Nwatu_Master_CV_10pt_Condensed.docx` - recruiter CV

## Important data/privacy rule

Do NOT upload real Sterling Bank/Holdings datasets, screenshots containing customer information, internal dashboards, credentials, transaction data, confidential vendor information, or proprietary system details.

The portfolio intentionally describes the work at a professional level and uses no confidential company data.

For dashboard demonstrations, use synthetic data that recreates the analytical problem, not copied company data.

## Recommended stack

1. GitHub for version control
2. Netlify or Vercel for deployment
3. Custom domain once the site is approved
4. Power BI screenshots or safe public demo embeds only when the underlying data is synthetic/public
5. Optional analytics: Plausible or GA4 after launch
6. Optional contact form: Formspree or Netlify Forms

## Fast launch

### Netlify
Drag the entire folder into Netlify's deploy interface, or connect the GitHub repository.

### GitHub Pages
Create a repository, upload the folder contents, then enable Pages from the repository settings.

### Vercel
Import the GitHub repository and deploy as a static site.

## Before publishing

Replace the LinkedIn placeholder URL in `index.html` with the exact LinkedIn profile URL.

Optionally add:
- professional headshot
- GitHub URL
- public Power BI portfolio links
- a safe, synthetic dashboard demo
- a downloadable PDF CV
- a short contact form
